# 绝地潜兵 2 实体数据浏览器

一个在线查看《绝地潜兵 2》实体数据的网页。项目通过 GitHub Pages 发布，打开 Pages 提供的网址即可使用，不需要安装任何东西。

**在线页面**：<https://darctor.github.io/Helldivers2_EntityDataBrowser/>

你可以在这里查看：

- 敌人、武器、战略配备等实体的生命值、受击部位、武器参数、爆炸物、阵营等数据。
- 数据之间的引用关系，例如一把武器用了哪颗射弹、射弹又引用了什么爆炸和伤害。
- 导出的原始 JSON 数据。

建议使用最新版 Chrome 或 Edge。

## 快速上手

1. 打开页面。
2. 在左上角的「搜索实体」里输入名字或哈希，页面会自动跳到匹配的实体。
3. 也可以点「实体列表」，先选大类，再选具体实体。
4. 进入实体页后，向下浏览各个组件；页面左侧的目录可以快速跳转。

## 页面功能

### 搜索实体

支持三种输入方式：

- 中文名，例如「解放者」。
- 英文名。
- 资源哈希，十六进制或十进制都可以。

输入后会立即切换到第一个匹配的实体。

### 实体列表

实体按大类分组，例如「主武器」「敌人」。

- 第一级显示大类。
- 点进大类后显示该类的全部实体。
- 再次打开列表时，会回到上次查看的大类和位置。

### 手动哈希读取

如果已经知道实体的资源哈希，可以直接输入。

- 点 `HEX` / `DEC` 在十六进制和十进制之间切换。
- 点「开始读取」跳转到该实体。

### 实体页

实体页顶部显示：

- 实体分类。
- 中文名和英文名。
- 资源哈希。
- 该实体有多少个组件有数据。

下方是各个组件区块，包含：

- **统计卡**：生命值、护甲、射速等单个数值。
- **表格**：受击部位、挂载槽、过热阶段等多行数据。
- **胶囊流**：弹匣图案、射弹类型等数组数据。
- **实体树**：挂载的无人机、射弹实体、库存装备等，可以一层层展开。

每个组件区块都可以单独折叠。没有数据的组件会收进页面底部的「空组件栏」，点一下即可展开查看。

### 数据链

数据链展示当前实体引用了哪些射弹、爆炸、伤害、状态效果等数据。

- 每一条引用从左边开始，向右展开成卡片。
- 卡片之间的连线表示父子关系。
- 点击任意卡片，会从它开始向下依次闪烁，方便追踪整条链。
- 每张卡片会写明它来自哪个组件字段，或经由哪个上级条目。
- 伤害卡片会标注伤害分类：射弹、爆炸、电弧、激光、状态效果、近战或射流伤害。

注意：数据链展示的是数据中的引用关系，游戏不一定实际使用每一条数据，请以实际测试为准。

### 受击部位表

生命值区块里的受击部位表会显示：

- 部位名称和部位 ID。
- 生命值、流血值、耐久度、护甲。
- 伤害传递、爆炸伤害倍率、死亡关系等。

窗口较窄时，表格会自动缩放；缩得太小时改为横向滚动。

### 原始数据

点页眉的「查看原始数据」可以浏览导出的 JSON 文件。

- 按文件夹进入下一级。
- 点 JSON 文件后，可以按哈希、序号或名称查找单条记录。
- 有 `type` 的 settings 文件可以输入 `type` 数值或枚举名查找。
- 点「平铺展示」可以展开完整 JSON，不受面板高度限制。

### 显示设置

- **主题**：页眉的「浅色 / 深色」按钮切换主题；没有手动切换时会跟随系统。
- **语言**：页眉的「中文 / EN」切换界面语言，实体名和字段名会一起切换。

## 常见问题

### 搜索不到实体

可以换一种输入方式：中文名、英文名、十六进制哈希、十进制哈希都支持。也可以直接从「实体列表」里选择。

### 页面显示「实体名与分类暂不可用」

说明名称数据没有加载成功。刷新页面后重试；如果一直这样，可能是网络暂时无法访问数据源。

### 数据链没有显示

该实体可能没有任何有效的外部数据引用，或者相关 settings 数据没有加载成功。可以先刷新页面重试。

### 第一次打开比较慢

部分数据文件很大，首次加载需要一些时间；加载完成后再搜索会快很多。

### 页面数据和我实际测试的不一样

网页展示的是导出数据。游戏版本、模式或实际判定条件都可能让结果不同，数据链和伤害分类仅作为参考。
